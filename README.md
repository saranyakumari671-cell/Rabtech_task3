# RabTech Task 3: Relational Schema Modeling and 3NF Normalization

## Project Overview
This project implements a relational database for an internship management system using MySQL.

## Database Tables
- Organizations
- Students
- Internships
- Applications
- Mentors
- Internship Mentors

## Implementation
- Created relational tables with primary and foreign keys.
- Added sample data to all six tables.
- Designed an ER diagram to illustrate database relationships.
- Verified a total of 35 sample records across the six tables.

## Project Files
- `schema.sql` — Database schema and table definitions.
- `seed_data.sql` — Sample data insertion statements.
- `Task3_ER_Diagram_Final.png` — Entity-relationship diagram.
